# 26號宇宙 (Universe 26) - POI 視覺化與全屬性自訂工具

## 🎯 功能介紹
這是一個獨立的開發者工具場景，專門用來在遊戲地圖上以**可視化滑鼠點選與參數面板**完整配置 22 個 POI 的所有屬性：

1. **三種幾何座標模式**：
   - **`📍 單門`**：點擊 1 格，設定標準單格門口。
   - **`🚪 雙格/多門`**：適用於 2 格寬大門（如商店、醫院），點選多個門口格，NPC 到達時自動分流防卡門。
   - **`🔷 範圍`**：連續點選頂點自訂多邊形活動範圍（如社交廣場），系統自動計算有效網格，**並自動排除不可通行的中央噴水池**！
2. **全套行為屬性設定面板（完全數據驅動，0 硬編碼）**：
   - **🏠 進屋/進森林隱藏 (Concealed)**：勾選即進入後淡出隱藏（自宅、商店、餐廳、伐木場森林、礦坑等）；取消勾選即為露天設施（農田、釣魚場、廣場）。
   - **🚪 門口進出朝向 (Entrance Direction)**：南門（朝上邁步進屋）、北門/後門（朝下邁步進屋）、東門、西門。
   - **🎯 抵達/活動半徑 (Radius)**：設定 0 ~ 15 格。室內建築為 0；農田或露天區域可設半徑，NPC 踏入半徑即算抵達。
   - **✏️ 自訂名稱**：可直接在輸入框修改 POI 顯示名稱。
3. **一鍵存檔**：
   - 點擊「💾 儲存配置 (Save)」直接將所有座標與屬性寫入 `data/poi_locations.json`。

## 🕹️ 操作方式
1. 在 Godot 編輯器中打開 `res://tools/poi_editor/poi_editor.tscn`。
2. 按下 **F6** 執行當前場景。
3. **視角移動**：
   - 按住 **滑鼠中鍵**（或單點模式下的右鍵）拖曳平移地圖。
   - 滑動 **滑鼠滾輪** 放大 / 縮小。
   - 鍵盤 **W / A / S / D** 或 **方向鍵** 移動鏡頭。
4. **設定步驟**：
   - 在左側清單點選欲設定的 POI。
   - 調整頂部的屬性（勾選是否隱藏、選擇門口朝向、調整半徑）。
   - 點選模式按鈕（單門 / 雙門 / 範圍），並在地圖上點擊對應格子。
   - 設定完畢後點擊「💾 儲存配置 (Save)」！

## 🗑️ 如何刪除本工具
當你完成所有 POI 設定後，**直接將整組 `tools/poi_editor/` 資料夾刪除**即可。
